# S4 · 实拍氛围桌面

不需要真人｜参考赞数 8,423

## 什么时候用

- 讲工作流、装备、书桌、日常
- 不想露脸
- 想营造「这个人真的在干活」的感觉

## 版式

竖版。俯拍或 45 度斜拍整张桌子。主体是屏幕 + 键盘 + 手写笔记。文字极少，最多底部一行小字或角落一个小标签。

## 字体

几乎不用字。要用就一行小字，放在角落，细黑体。

## 配色

暗调、暖光、单一光源。桌面木色 + 屏幕冷光。

## 关键元素

- 屏幕上要能看到真实内容（代码、表格、聊天）
- 桌上散落手写便签
- 一杯水或咖啡，制造生活痕迹

## 提示词模板

```
## 通用约束（每次都要带，别省）

- **画布 `1024x1440`，不要用 1536。** 1440 = 1365（3:4 需要的高度）+ 75（水印出血）
- 出图后跑 `python scripts/strip_watermark.py <目录> --ratio 3:4`，自动上裁 0 / 下裁 75，结果 1024×1365
- 画面**最下方 6%** 保持干净，不放任何文字
- **左上角 12%** 区域留空（页码标签要压在那里）
- 主标题左右各留 **6%–8%** 安全边距
- 中文串一律用「」括起来，并写明字数与字号
- 配色给上限和 HEX，不写「配色和谐」
- 必写禁用项：不要 3D 渲染、不要塑料光泽、不要渐变光晕、不要写实照片（照片类风格除外）
- 所有中文清晰、笔画正确、无错字、无乱码

> 🔴 实测：模型**不会**为后处理留白。明确写「上方 12% 留空、标题从 14% 处开始」也没用，
> 它照样把标题画在最顶上。所以顶部不裁 —— 尺寸上就解决掉。

---

竖版 3:4 实拍照片，45 度斜俯拍一张工作桌面。桌上有一台打开的笔记本电脑，屏幕显示{代码/表格/聊天界面}，旁边是机械键盘、一本摊开的手写笔记本、两支笔、一杯水。暖色台灯从左上打光，环境偏暗，有真实阴影。画面底部右侧一行很小的白字：「{一句话}」。手机随手拍质感，轻微噪点。不要摆拍得太整齐、不要 3D、不要插画、不要滤镜。
```

## 排雷

- 屏幕别糊成一片白
- 别打多光源（会假）
- 文字别超过一行
