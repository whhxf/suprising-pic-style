# S2 · 机构科普海报

不需要真人｜参考赞数 92,000

## 什么时候用

- 做系列科普，要品牌感
- 单条讲一个反常识知识点
- 想被收藏、被转发到群里

## 版式

竖版。顶部 25% 是超大海报标题（2 行，其中一行是主体词，字号最大）；中间 55% 是主视觉照片；底部一行小字副标题；左上角放账号 logo。

## 字体

超粗黑体或综艺体。主标题用高饱和色块字，副标题用细黑体小字，形成强对比。

## 配色

深色或高饱和底 + 一个主色（蓝/橙）+ 白字。三色以内。

## 关键元素

- 主体词单独一行、字号翻倍
- 实景照片抠图或叠底
- 角落有机构标识，建立可信度

## 提示词模板

```
## 通用约束（每次都要带，别省）

- **画布 `1024x1440`，不要用 1536。** 1440 = 1365（3:4 需要的高度）+ 75（水印出血）
- 出图后跑 `python scripts/strip_watermark.py <目录> --ratio 3:4`，自动上裁 0 / 下裁 75，结果 1024×1365
- 画面**最下方 6%** 保持干净，不放任何文字
- **左上角 12%** 区域留空（页码标签要压在那里）
- 主标题左右各留 **6%–8%** 安全边距
- 中文串一律用「」括起来，并写明字数与字号
- 配色给上限和 HEX，不写「配色和谐」
- 必写禁用项：不要 3D 渲染、不要塑料光泽、不要渐变光晕、不要写实照片（照片类风格除外）
- 所有中文清晰、笔画正确、无错字、无乱码

> 🔴 实测：模型**不会**为后处理留白。明确写「上方 12% 留空、标题从 14% 处开始」也没用，
> 它照样把标题画在最顶上。所以顶部不裁 —— 尺寸上就解决掉。

---

竖版 3:4 科普海报。深{蓝/墨绿}色背景，带轻微纸张颗粒。顶部两行超大中文标题，第一行字号是第二行的 1.6 倍，粗黑体，{亮黄/白}色：「{主体词}」「{一句话说明}」。中间放一张{主题物}的写实照片，抠图后压在背景上，边缘干净。底部一行细黑体小字副标题：「{补充说明}」。左上角一个小号白色机构标识占位。整体像自然博物馆的展板。不要卡通、不要渐变光晕、不要 3D 渲染。
```

## 排雷

- 标题别超过两行
- 照片别用示意图代替
- 别用超过三种颜色
