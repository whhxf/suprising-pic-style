# S3 · 真人 + 数据背书

需要真人出镜｜参考赞数 28,000

## 什么时候用

- 有可晒的真实数字（点赞、收藏、收入、涨粉）
- 方法论 + 结果一起讲
- 卖课、接单、做服务的转化帖

## 版式

竖版。人物占 60%，偏左或偏右。空白侧贴 2–3 张数据卡片（截图或纯数字卡），卡片有圆角和白边。标题压在人物上方或下方，副标题用「（附…）」句式。

## 字体

标题粗黑体 + 描边；数据卡里的数字用特大号，单位小字；卡片标题用细黑体。

## 配色

人物区自然色，数据卡用纯白或浅色底 + 一个高饱和数字色（蓝/红）。

## 关键元素

- 数字要能看清（截图别糊）
- 卡片微微倾斜，像随手贴的
- 副标题写清「附什么」

## 提示词模板

```
## 通用约束（每次都要带，别省）

- **画布 `1024x1440`，不要用 1536。** 1440 = 1365（3:4 需要的高度）+ 75（水印出血）
- 出图后跑 `python scripts/strip_watermark.py <目录> --ratio 3:4`，自动上裁 0 / 下裁 75，结果 1024×1365
- 画面**最下方 6%** 保持干净，不放任何文字
- **左上角 12%** 区域留空（页码标签要压在那里）
- 主标题左右各留 **6%–8%** 安全边距
- 中文串一律用「」括起来，并写明字数与字号
- 配色给上限和 HEX，不写「配色和谐」
- 必写禁用项：不要 3D 渲染、不要塑料光泽、不要渐变光晕、不要写实照片（照片类风格除外）
- 所有中文清晰、笔画正确、无错字、无乱码

> 🔴 实测：模型**不会**为后处理留白。明确写「上方 12% 留空、标题从 14% 处开始」也没用，
> 它照样把标题画在最顶上。所以顶部不裁 —— 尺寸上就解决掉。

---

竖版 3:4 封面。一位{性别}真人半身，占画面{左/右}侧 60%，自然室内光。另一侧空白处贴 2 张圆角白色数据卡片，微微倾斜。第一张卡片上写特大号数字「{数字}」和小字「{指标名}」；第二张写「{第二个数字}」和「{指标名}」。人物上方叠一行粗黑体标题，白字红描边：「{标题}」。下方一行小字：「（{附什么}）」。卡片边缘有轻微投影，像贴上去的。不要美颜、不要 3D、不要发光特效。
```

## 排雷

- 数字别造假、别糊到看不清
- 卡片别超过 3 张
- 别把人物压到只剩一角
