# S7 · 极简文字卡

不需要真人｜参考赞数 4,639

## 什么时候用

- 有一个足够强的结论 / 数字 / 反差
- 没有素材、没有出镜条件
- 批量做系列，靠统一版式建立识别

## 版式

竖版。顶部一个小图形（卡通头像 / 图标），中间超大字占画面 60%，3–5 行。底部留白。

## 字体

超粗黑体，字号大到接近满宽。关键词用荧光笔色块涂底（不是变色）。

## 配色

纯白或浅米底 + 黑字 + 一个荧光色（紫/黄/绿）做高亮。

## 关键元素

- 顶部图形是唯一装饰，别再加
- 关键词涂底，一次最多 3 处
- 标点用全角，句号可省

## 提示词模板

```
## 通用约束（每次都要带，别省）

- **画布 `1024x1440`，不要用 1536。** 1440 = 1365（3:4 需要的高度）+ 75（水印出血）
- 出图后跑 `python scripts/strip_watermark.py <目录> --ratio 3:4`，自动上裁 0 / 下裁 75，结果 1024×1365
- 画面**最下方 6%** 保持干净，不放任何文字
- **左上角 12%** 区域留空（页码标签要压在那里）
- 主标题左右各留 **6%–8%** 安全边距
- 中文串一律用「」括起来，并写明字数与字号
- 配色给上限和 HEX，不写「配色和谐」
- 必写禁用项：不要 3D 渲染、不要塑料光泽、不要渐变光晕、不要写实照片（照片类风格除外）
- 所有中文清晰、笔画正确、无错字、无乱码

> 🔴 实测：模型**不会**为后处理留白。明确写「上方 12% 留空、标题从 14% 处开始」也没用，
> 它照样把标题画在最顶上。所以顶部不裁 —— 尺寸上就解决掉。

---

竖版 3:4 极简文字卡。纯{白/米白}背景，没有任何纹理。顶部居中一个小卡通图标（{一个圆脸小角色/一个简单线框图标}），占画面宽度 12%。中间是 4 行超粗黑体中文，字号很大、几乎撑满画面宽度，颜色深灰近黑：「{第一行}」「{第二行}」「{第三行}」「{第四行}」。其中「{关键词1}」「{关键词2}」两处用{淡紫/淡黄}荧光笔色块涂底，文字压在色块上。底部留大片空白。不要任何其他装饰、不要边框、不要渐变。
```

## 排雷

- 别超过 5 行
- 高亮别超过 3 处
- 别加第二个图形
