# S8 · 爆炸贴纸标题

不需要真人｜参考赞数 3,973

## 什么时候用

- 有强数字或强反差
- 目标是被点开，不是被收藏
- 账号本身调性偏活泼

## 版式

竖版。真人或产品占中下，标题用两三种字号混排、角度微斜、互相压叠。加手绘箭头或爆炸形状。

## 字体

三种以上字号混排：数字最大（红），动词次之（黑），名词再次。全部带描边。

## 配色

红 + 黑 + 白，三色硬碰。背景可以是真人或纯色。

## 关键元素

- 数字单独放大
- 手绘箭头指向主体
- 标题块微微旋转 -5° 到 5°

## 提示词模板

```
## 通用约束（每次都要带，别省）

- **画布 `1024x1440`，不要用 1536。** 1440 = 1365（3:4 需要的高度）+ 75（水印出血）
- 出图后跑 `python scripts/strip_watermark.py <目录> --ratio 3:4`，自动上裁 0 / 下裁 75，结果 1024×1365
- 画面**最下方 6%** 保持干净，不放任何文字
- **左上角 12%** 区域留空（页码标签要压在那里）
- 主标题左右各留 **6%–8%** 安全边距
- 中文串一律用「」括起来，并写明字数与字号
- 配色给上限和 HEX，不写「配色和谐」
- 必写禁用项：不要 3D 渲染、不要塑料光泽、不要渐变光晕、不要写实照片（照片类风格除外）
- 所有中文清晰、笔画正确、无错字、无乱码

> 🔴 实测：模型**不会**为后处理留白。明确写「上方 12% 留空、标题从 14% 处开始」也没用，
> 它照样把标题画在最顶上。所以顶部不裁 —— 尺寸上就解决掉。

---

竖版 3:4 封面。背景是{真人半身/纯亮色底}。上面叠一组爆炸感中文标题：一个巨大红色数字「{数字}」带白描边，旁边黑色粗字「{动词}」，下面白色粗字「{名词}」，三块字号差异极大、互相轻微压叠、各自旋转 ±5 度。加一个手绘红色箭头指向{主体}。整体像便利店促销贴纸。不要优雅、不要留白、不要衬线体。
```

## 排雷

- 数字必须真实可查
- 别用超过 3 种颜色
- 一条内容只能用一次这种风格
