# S6 · 手绘插画

不需要真人｜参考赞数 6,462

## 什么时候用

- 观点 / 感受 / 反常识结论
- 不想露脸也不想做图表
- 想显得不像广告

## 版式

竖版。上半 45% 一张手绘插画（一个人在做一件事），下半 55% 两行粗体标题 + 一行小字说明。四周留白多。

## 字体

标题用圆润的粗黑体（不是锐利那种），黑或深棕；说明用小字，行距松。

## 配色

米白 / 奶油色底，插画用 3–4 个低饱和色（砖红、墨绿、芥末黄、深蓝）。

## 关键元素

- 人物比例夸张、头大身小
- 线条有手抖感，不追求完美
- 插画只讲一件事，不堆元素

## 提示词模板

```
## 通用约束（每次都要带，别省）

- **画布 `1024x1440`，不要用 1536。** 1440 = 1365（3:4 需要的高度）+ 75（水印出血）
- 出图后跑 `python scripts/strip_watermark.py <目录> --ratio 3:4`，自动上裁 0 / 下裁 75，结果 1024×1365
- 画面**最下方 6%** 保持干净，不放任何文字
- **左上角 12%** 区域留空（页码标签要压在那里）
- 主标题左右各留 **6%–8%** 安全边距
- 中文串一律用「」括起来，并写明字数与字号
- 配色给上限和 HEX，不写「配色和谐」
- 必写禁用项：不要 3D 渲染、不要塑料光泽、不要渐变光晕、不要写实照片（照片类风格除外）
- 所有中文清晰、笔画正确、无错字、无乱码

> 🔴 实测：模型**不会**为后处理留白。明确写「上方 12% 留空、标题从 14% 处开始」也没用，
> 它照样把标题画在最顶上。所以顶部不裁 —— 尺寸上就解决掉。

---

竖版 3:4 手绘插画封面。米白色纸质感背景。上半部分画一个{卡通人物：短发/戴眼镜}坐在{桌前用电脑/沙发上刷手机}，线条是手绘的、略有抖动，填色是低饱和的{砖红/墨绿/芥末黄}，扁平无阴影。下半部分两行粗体中文标题，圆润黑体，深棕色：「{第一行}」「{第二行}」。标题下面一行小字：「{说明}」。四周留白充足。不要 3D、不要写实、不要渐变、不要塑料质感。
```

## 排雷

- 插画别画细节（会变脏）
- 颜色别超过 4 个
- 标题别压在插画上
