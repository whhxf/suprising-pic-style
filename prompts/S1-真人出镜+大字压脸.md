# S1 · 真人出镜 + 大字压脸

需要真人出镜｜参考赞数 189,000

## 什么时候用

- 个人号 / 有真人可拍
- 观点型、经验型、教程型
- 需要建立信任，转化到主页或私信

## 版式

竖版 3:4。人物占画面 55%–70%，头肩近景，脸偏中下。标题压在上方 1/3，2–3 行，字号占画面宽度 80%+。副标题用括号小字。

## 字体

粗黑体，白字 + 2–4px 红/黑描边（保证任何背景上都读得清）。副标题小一号，同样描边。

## 配色

背景是真实环境（白墙、书架、工位），不加滤镜。标题红或白，最多一个强调色。

## 关键元素

- 真人眼神不看镜头（看手上、看旁边）更自然
- 手持道具：眼镜、手机、打印纸
- 背景留一点生活杂物，别擦太干净

## 提示词模板

```
## 通用约束（每次都要带，别省）

- **画布 `1024x1440`，不要用 1536。** 1440 = 1365（3:4 需要的高度）+ 75（水印出血）
- 出图后跑 `python scripts/strip_watermark.py <目录> --ratio 3:4`，自动上裁 0 / 下裁 75，结果 1024×1365
- 画面**最下方 6%** 保持干净，不放任何文字
- **左上角 12%** 区域留空（页码标签要压在那里）
- 主标题左右各留 **6%–8%** 安全边距
- 中文串一律用「」括起来，并写明字数与字号
- 配色给上限和 HEX，不写「配色和谐」
- 必写禁用项：不要 3D 渲染、不要塑料光泽、不要渐变光晕、不要写实照片（照片类风格除外）
- 所有中文清晰、笔画正确、无错字、无乱码

> 🔴 实测：模型**不会**为后处理留白。明确写「上方 12% 留空、标题从 14% 处开始」也没用，
> 它照样把标题画在最顶上。所以顶部不裁 —— 尺寸上就解决掉。

---

竖版 3:4 封面照片风格。一位亚洲{性别}坐在{场景：书桌前/白墙前}，近景半身，{动作：手扶眼镜/低头看手机/拿着一张纸}，视线不看镜头，表情专注。真实室内光，手机拍摄质感，轻微颗粒，不磨皮不滤镜。画面上方三分之一处叠两行超大中文标题，粗黑体，白色字配 3px {红/黑}色描边：「{主标题第一行}」「{主标题第二行}」。标题下方一行小字带括号：「（{副标题}）」。标题左右各留 6% 安全边距。不要美颜、不要影棚布光、不要 3D、不要插画。
```

## 排雷

- 不要把人修成网红脸
- 标题不要超过 3 行
- 不要把标题放在脸的正中间
