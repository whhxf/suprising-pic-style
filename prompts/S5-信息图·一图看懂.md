# S5 · 信息图 / 一图看懂

不需要真人｜参考赞数 7,661

## 什么时候用

- 工具盘点、层级分类、流程拆解
- 一条内容要装 10 个以上信息点
- 目标是收藏，不是点赞

## 版式

竖版。顶部 15% 通栏色块放标题；中间 70% 是结构图（金字塔 / 树状 / 四象限 / 流程）；两侧贴分类标签；底部 8% 一句总结 + 页码。

## 字体

标题粗黑体白字；层级名小字；标签用圆角小胶囊。字号层级必须拉开 3 档以上。

## 配色

浅色底 + 每层一个渐变色（同色系明度递进）。标题栏用最深的主色。

## 关键元素

- 每层有图标（真实产品 logo 或线性图标）
- 侧边标签说明这一层是干什么的
- 底部一句「先想清楚…再…」的行动句

## 提示词模板

```
## 通用约束（每次都要带，别省）

- **画布 `1024x1440`，不要用 1536。** 1440 = 1365（3:4 需要的高度）+ 75（水印出血）
- 出图后跑 `python scripts/strip_watermark.py <目录> --ratio 3:4`，自动上裁 0 / 下裁 75，结果 1024×1365
- 画面**最下方 6%** 保持干净，不放任何文字
- **左上角 12%** 区域留空（页码标签要压在那里）
- 主标题左右各留 **6%–8%** 安全边距
- 中文串一律用「」括起来，并写明字数与字号
- 配色给上限和 HEX，不写「配色和谐」
- 必写禁用项：不要 3D 渲染、不要塑料光泽、不要渐变光晕、不要写实照片（照片类风格除外）
- 所有中文清晰、笔画正确、无错字、无乱码

> 🔴 实测：模型**不会**为后处理留白。明确写「上方 12% 留空、标题从 14% 处开始」也没用，
> 它照样把标题画在最顶上。所以顶部不裁 —— 尺寸上就解决掉。

---

竖版 3:4 中文信息图。顶部一条{蓝}色圆角通栏，里面写白色粗黑体标题：「{标题}」。中间是一个{五层金字塔/树状图}，从上到下每一层一种{蓝色系}渐变色，每层里放 3–7 个线性图标和对应中文名（{名称1}、{名称2}…）。图形左右两侧各贴 2–3 个白色圆角小标签，标签里是中文分类名：「{分类1}」「{分类2}」。底部一条{蓝}色通栏，写一行白色小字：「{总结句}」。最底部灰色小字：「{系列名} 1/8」。扁平化，网格对齐，留白干净。所有中文清晰正确。
```

## 排雷

- 每层别超过 7 个图标
- 别用超过 4 档字号
- 别把标签压在图形上
