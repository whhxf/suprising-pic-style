# 爆款图文封面风格库

八种经实测的小红书 / 公众号图文封面风格。每种都给视觉配方、可直接填变量的出图提示词、排雷清单，以及裁水印的脚本。

不是图片素材包，是**生成配方**。

---

## 它能解决什么

做图文卡片时，最常见的两个问题：

1. **不知道走哪种视觉路线** —— 于是每次都做成「白底黑字 + 一句大话」，没人点。
2. **每次都要重新想风格** —— 想出来的多半是「宣传图」，不是「封面」。

这个库把 8 种被验证过的封面结构拆开，写成能直接用的提示词。选一种，填内容，出图。

## 它不解决什么

- 不提供成品图。参考图是别人的笔记封面，见 [examples/](examples/)
- 不保证数据。样本只有 AI / 效率类关键词，其他赛道规律可能不同

## 八种风格

| ID | 风格 | 一眼特征 | 要真人 | 参考赞数 |
|---|---|---|---|---|
| S1 | 真人出镜 + 大字压脸 | 脸占大半，红白描边大字压上方 | 是 | 18.9 万 |
| S2 | 机构科普海报 | 超大海报字 + 实景照片 + 角落标识 | 否 | 9.2 万 |
| S3 | 真人 + 数据背书 | 人 + 旁边贴点赞 / 收入数字卡 | 是 | 2.8 万 |
| S4 | 实拍氛围桌面 | 暗调桌面俯拍，几乎没字 | 否 | 8.4 千 |
| S5 | 信息图 · 一图看懂 | 金字塔分层，每层一排图标 | 否 | 7.7 千 |
| S6 | 手绘插画 | 米白底 + 卡通小人 + 两行标题 | 否 | 6.5 千 |
| S7 | 极简文字卡 | 纯白底，超大字，关键词涂荧光 | 否 | 4.6 千 |
| S8 | 爆炸贴纸标题 | 巨大红数字 + 黑字 + 手绘箭头 | 否 | 4.0 千 |

每种风格的完整说明在 [prompts/](prompts/)。

## 怎么选

1. **能露脸吗？** 能 → 有真实数字用 **S3**，没有用 **S1**
2. **不能露脸，内容有 10 个以上信息点？** → **S5**
3. **不能露脸，只有 1 个强结论？** 有数字反差用 **S8**，没有用 **S7**
4. **讲工作流 / 装备 / 日常？** → **S4**
5. **讲观点 / 情绪 / 方法论？** → **S6**
6. **做系列科普、要品牌感？** → **S2**

## 三步用起来

**1. 选风格，取提示词**

```bash
open prompts/S7-极简文字卡.md
```

把模板里的 `{}` 换成实际内容。

**2. 出图**

画布固定 `1024x1440`，不是 1536。原因见下一节。

**3. 裁水印**

```bash
python scripts/strip_watermark.py <图片目录> --ratio 3:4
```

结果：`1024×1365`，比例 0.7502，右下角水印已清，顶部一格没动。

---

## 尺寸为什么是 1024×1440

这是整个库里最值钱的一条实测结论。

| | 1536 画布 | **1440 画布** |
|---|---|---|
| 裁成 3:4 要裁多少 | 171 px | **75 px** |
| 裁在哪 | 上 83 + 下 88 | **只裁下 75** |
| 标题会被切吗 | **会** | 不会 |

`1440 = 1365（3:4 需要的高度）+ 75（水印出血）`

**为什么不能靠提示词解决**：实测两次，明确写了「上方 12% 留空、标题从 14% 处开始」，
模型仍然把标题画在最顶上。**文字贴顶是它的默认行为，改提示词改不动。**

所以正解不是在提示词里求它留白，而是**把后处理的量算进画布尺寸**。

## 水印实测数据

出图工具在右下角固定叠加「AI生成 / WORKBUDDY」：

| 项 | 数值（1024 宽画布） |
|---|---|
| 尺寸 | 约 130 × 70 px |
| 距右 | 约 8 px |
| 距底 | 约 10 px |
| 1440 画布上沿 | y ≈ 1380 |

裁到 1365，留 15 px 余量。浅色背景上水印是白底白字，肉眼看不出但文件里在，所以一律裁。

> ⚠️ **合规**：《人工智能生成合成内容标识办法》要求 AI 生成内容带显式标识。
> 裁掉平台水印后，请在发布文案里补一句「配图由 AI 生成」，或用平台自带的声明开关。
> **不要用模糊、涂抹去水印** —— 会留脏块，也属于篡改标识。

## 目录

```
styles.json              机器可读的风格数据，唯一数据源
prompts/                 八份人读的提示词文档
scripts/strip_watermark.py   裁水印 / 裁出血框
scripts/check_styles.py      校验 styles.json 结构
docs/风格库.md           完整调研记录：样本、共同点、局限
examples/                参考图说明（原图不入库，见目录内 README）
```

## 加一种新风格

1. 在 `styles.json` 的 `styles` 数组里加一条，字段照现有条目填全
2. 跑 `python scripts/check_styles.py` 校验
3. 在 `prompts/` 里加同名 md，模板直接引用 `prompt_template`
4. 更新 README 的表格和决策树

`styles.json` 每条必须有：`id` / `name` / `when_to_use` / `layout` / `typography` /
`color` / `elements` / `prompt_template` / `avoid` / `needs_face`。

## 数据来源

2026-10-20，小红书站内搜索按「最热」排序，6 个关键词（AI工具 / AI科普 / 提示词 / AI绘画 /
效率工具 / AI搞钱），浏览 720 张卡片，去重 152 篇，最高赞 18.9 万。

**局限**：点赞不等于阅读量；算法会放大已爆内容；8 个分类是归纳出来的，边界有交叉。

详见 [docs/风格库.md](docs/风格库.md)。
