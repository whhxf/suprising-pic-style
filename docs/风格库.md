## 二、逐个拆：好在哪、什么时候用

### S1 真人出镜 + 大字压脸

**为什么有效**：脸是最快的注意力钩子，字是最快的信息传递。两个叠在一起，0.3 秒内完成「谁在说」和「说什么」。

**配方**：
- 头肩近景，人占 55%–70%，脸偏中下
- 标题压上方 1/3，2–3 行，占画面宽度 80% 以上
- 白字 + 3px 红描边（背景再乱也读得清）
- 副标题用括号小字：「（建议码住）」
- 眼神**不看镜头**，看手上或看旁边

**别做**：修成网红脸、标题超过 3 行、标题盖住眼睛。

---

### S2 机构科普海报

**为什么有效**：看起来「有出处」。同一句话，加个机构标识，可信度立刻不一样。

**配方**：
- 顶部 25% 超大海报字，主体词单独一行、字号翻倍
- 中间 55% 实景照片（不是示意图）
- 底部一行细黑体小字
- 左上角放账号标识
- 深底 + 一个主色 + 白字，三色封顶

**别做**：标题超过两行、用示意图代替照片、颜色超过三种。

---

### S3 真人 + 数据背书

**为什么有效**：把「我说有用」变成「数据说有用」。副业、涨粉、收入类几乎全用这套。

**配方**：
- 人占 60%，另一侧留白
- 贴 2–3 张圆角数据卡，微微倾斜，像随手贴的
- 数字特大，单位小
- 副标题写清「附什么」：「（附提示词）」「（附接单流程）」

**别做**：数字造假、卡片超过 3 张、把人物压到只剩一角。

---

### S4 实拍氛围桌面

**为什么有效**：不承诺、不吆喝，只展示「这个人真的在干活」。适合建立长期信任，不适合单条爆量。

**配方**：
- 45 度斜俯拍，整张桌子
- 屏幕里要有真实内容（代码、表格、聊天）
- 暖光单光源，环境偏暗
- 散落手写便签，一杯水
- 文字最多一行，放角落

**别做**：摆得太整齐、多光源（会假）、屏幕糊成白块。

---

### S5 信息图 / 一图看懂

**为什么有效**：收藏率最高的一类。读者收藏的不是观点，是「以后要查的表」。

**配方**：
- 顶部通栏标题，底部通栏一句总结 + 页码
- 中间结构图：金字塔 / 树状 / 四象限 / 流程
- 每层一个同色系渐变色，每层 3–7 个图标
- 两侧贴分类标签，说明「这一层是干什么的」
- 底部行动句：「先想清楚要解决什么问题，再按层找工具」

**别做**：每层超过 7 个图标、超过 4 档字号、标签压在图形上。

---

### S6 手绘插画

**为什么有效**：低攻击性。看起来像笔记，不像广告，适合观点和情绪。

**配方**：
- 米白 / 奶油底
- 上半 45% 插画，下半 55% 两行标题 + 一行小字
- 人物头大身小，线条有抖动
- 3–4 个低饱和色：砖红、墨绿、芥末黄、深蓝

**别做**：插画画太细（会变脏）、颜色超过 4 个、标题压在插画上。

---

### S7 极简文字卡

**为什么有效**：零成本，纯靠文案。前提是那句话本身够狠 —— 有数字、有反差、有反常识。

**配方**：
- 纯白底，无纹理
- 顶部一个小图形（占宽 12%），是唯一装饰
- 中间 3–5 行超粗黑体，几乎撑满宽度
- 关键词用荧光色块涂底，一次最多 3 处

**别做**：超过 5 行、高亮超过 3 处、再加第二个图形。

---

### S8 爆炸贴纸标题

**为什么有效**：冲击力最强。代价是容易显得廉价，用多了伤账号调性。

**配方**：
- 巨大红数字 + 黑动词 + 白名词，三种字号混排
- 每块旋转 ±5 度，互相压叠
- 手绘箭头指向主体
- 红 + 黑 + 白，三色硬碰

**别做**：数字不可查、超过三种颜色、连续两条都用这个。

## 三、怎么选（决策树）

1. **能露脸吗？** 能 → 有真实数字用 **S3**，没有用 **S1**
2. **不能露脸，内容有 10 个以上信息点？** → **S5**
3. **不能露脸，只有 1 个强结论？** 有数字反差用 **S8**，没有用 **S7**
4. **讲工作流 / 装备 / 日常？** → **S4**
5. **讲观点 / 情绪 / 方法论？** → **S6**
6. **做系列科普、要品牌感？** → **S2**

## 四、八种风格的共同点（比风格本身更重要）

1. **3:4 竖版，没有例外。** 152 篇里没找到横版爆款。
2. **字必须大到手机上不用眯眼。** 主标题占画面宽度 70% 以上。
3. **只用 2–3 种颜色。** 多一种是噪点，不是丰富。
4. **一个画面只讲一件事。** 想讲两件，就做两张。
5. **标题里必须有具体的东西**：数字、名词、时间。没有具体词的标题，在这批样本里几乎没进前列。
6. **副标题负责补一句「凭什么信你」**：附什么、建议码住、我试过了。

## 五、怎么调用

机器可读版在仓库根目录 `styles.json`，每条含：

- `id` / `name` / `file`（对应示例图）
- `when_to_use`（什么时候选它）
- `layout` / `typography` / `color` / `elements`（视觉配方）
- `prompt_template`（可直接填变量的出图提示词）
- `avoid`（排雷清单）
- `needs_face`（是否需要真人）

用法：先按 `decision_tree` 选 id，再把 `prompt_template` 里的 `{}` 换成实际内容，最后逐条对照 `avoid`。

## 六、这份样本的局限

- **只有 AI / 效率类关键词。** 美妆、母婴、家居的封面规律可能不同，不能直接套。
- **点赞不等于阅读。** 小红书不公开阅读量，点赞只能当相对排序。
- **算法推荐会放大已爆内容。** 样本偏向「最近正在被推的」，不是「历史上最好的」。
- **8 个风格是我归的类**，原作者没这么分。归类有主观成分，边界会有交叉。
